Element Web / Desktop **1.12.29**, merged with the `oss96/element-web` fork's features. Upstream is synced to `element-hq/element-web@c9cff69c` (2026-09-22).

## Downloads

- **`Element-Setup-1.12.29-fork.1-x64.exe`**: per-user Windows installer (Squirrel), no admin needed. It is **unsigned**, so Windows SmartScreen will warn you: click *More info → Run anyway*. Close any running Element before you install.
- `element-web-1.12.29-fork.1.tar.gz`: the web build. Add your own `config.json` before serving it.
- `SHA256SUMS.txt`: checksums for everything above.

Your user data in `%AppData%\Element` is kept across installs.

## New from upstream since the last fork sync (1.12.27 → 1.12.29)

### Features
- User status is on by default, with length limits, and its UI is disabled when you're offline
- Unified media previews for files, URL previews, upload confirmation and old media bodies
- Bundled URL previews in encrypted rooms: send, receive and edit them in the edit composer
- Intentional-mention push rules show up in notification settings
- Room list: the resizer shortcuts are listed in Keyboard settings, rooms opened in the spotlight show up in the list, new analytics, faster
- Labs: PDF viewer and a new timeline panel
- Tokenizer mode for message search
- Desktop: FOSS parts of X.509 hardware-key identity verification (IPC + module API 2.2.0)
- Desktop: the Wayland application ID matches the `.desktop` file on Linux
- The app version is logged at startup on every platform
- `M_INVITE_BLOCKED` is handled

### Fixes
- **Keyboard shortcuts now match case-insensitively, so caps lock no longer breaks them.** This is merged with the fork's numpad-aware / physical-key matching.
- Desktop: no crash on Windows/macOS when keychain access is denied
- Desktop: clearing data no longer restarts the app
- Desktop: ⌘W / close on macOS hides the app instead of leaving it without a window
- Desktop: authenticated avatar fetching for the macOS Touch Bar is fixed
- OAuth logout no longer breaks when it starts while offline
- Key storage shows as out of sync when backup download fails. A forgotten recovery key no longer forces an identity reset
- Jumping to a date goes to the start of the day in local time, not UTC
- Message editing: the autocomplete/formatting bar is visible again, and URL-preview spacing and alignment are fixed
- A thread is no longer shown bright red when you're mentioned in it
- PDF zoom anchoring, call-tile bubble padding and user status overflow are fixed
- Leaving a restricted room no longer says you need an invite to return
- Security: maplibre-gl updated to v6

### Platform / tooling
- Electron **44.3.0**, nx 23.2, vite 5, compound-web 10.1, Node 24.21
- `hak` is gone and Seshat now comes from the `@matrix-org/seshat` package
- The legacy Module & Customisation API was removed. Use the module API instead
- The remaining jest tests were migrated to vitest

## Fork features (unchanged in this release)

- **Customisable keyboard shortcuts.** Click-to-rebind, clear, reset and reset-all in *Settings → Keyboard*, with numpad-aware bindings
- **Global hotkeys (desktop).** "Make global" on Calls and Navigation shortcuts, through Electron `globalShortcut`
- **Call shortcuts.** Mic, camera and a new *toggle incoming audio* shortcut (`Ctrl+Alt+D`), for both 1:1 calls and Element Call group calls, with confirmation tones
- **In-call indicators.** Mic / camera / incoming-audio pills over group calls. Speaking pulse and a primary-tile mic indicator in 1:1 calls
- **Screenshare audio.** System audio for screens. Per-application audio for windows on Windows. Loopback audio is captured without echo cancellation or noise suppression, so it doesn't duck when people speak

## Build / infrastructure changes in this fork
- New `fork-release.yml` GitHub Actions workflow. It tests the fork, builds the web tarball and the Windows installer, and publishes releases like this one.
- Upstream's agent guide is kept as `AGENTS.upstream.md`, and the fork docs are refreshed.

## Known limitations
- The Windows installer is unsigned
- Per-application screenshare audio works on Windows only
- Incoming-audio mute and the speaking pulse for Element Call need matching Element Call support. On vanilla Element Call the indicator updates but remote audio keeps playing
- Global hotkeys stop when the window is closed, because closing quits the app
